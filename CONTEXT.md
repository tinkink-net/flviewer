# CONTEXT.md — flviewer

**Bounded context:** pure client-side, in-browser file preview.

flviewer fetches (or receives already-held) file bytes and renders them in the browser
with its own minimal viewer UI. No server component, no framework dependencies.
Supports **images**, **PDF**, **video/audio**, and the **text family** (plain text/code,
JSON, CSV, XML, Markdown-as-rendered-HTML); anything else resolves to a typed error.

## Ubiquitous language

| Term                        | Definition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Source**                  | The value identifying bytes to preview: http(s) URL (`string`/`URL`), `Blob`, `File`, `ArrayBuffer`, `Uint8Array`. URLs are fetched inside the viewer, honoring `requestInit`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **requestInit**             | A `RequestInit` object (headers, credentials, method) applied when fetching URL sources.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Overlay**                 | Fullscreen modal preview created by `open(source)`. Locks page scroll, owns the Close control, one at a time (new `open()` replaces the current one).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Embed**                   | Preview rendered inside a caller-provided container via `mount(el, source)`. Same Core, no Close control.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Core**                    | The single shared renderer (DOM structure + toolbar + state machine) mounted by every surface. Exists exactly once; surfaces are thin adapters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Controller**              | Handle returned by `open()`/`mount()`: `update(source)`, `destroy()` (idempotent), `on(event, cb)`, and `close()` (Overlay only).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **`<fl-viewer>`**           | Custom element wrapping the Core. Renders in light DOM. Attributes: `src`; complex values (e.g. `requestInit`) via properties. Same semantics as the Controller.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Detection chain**         | Format sniffing order: `Content-Type` MIME → URL/`File.name` extension → magic bytes (`%PDF-`, image signatures, media containers) — with the text sniff (UTF-8 validity + NUL rejection, sub-kind refinement) ordered before magic bytes, but a known binary signature still wins over the text claim. A `PK\x03\x04` container with no MIME/extension claim is resolved by a **sync central-directory scan** of a tail slice (entry names are raw header bytes — no zip dependency); a `D0 CF 11 E0` (CFB) container is resolved by a **minimal CFB directory walk** (encrypted OOXML vs legacy binary, authoritative over extension). Yields `image`, `pdf`, `video`, `audio`, `text`, `docx`, `xlsx`, `pptx`, or `unsupported`. |     |
| **Browser-decodable image** | v1 image support = whatever the browser's own decoder handles (PNG, JPEG, GIF, WebP, AVIF, BMP, ICO, SVG-as-static-image). SVG interactivity is out of scope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Streaming media**         | Video/audio URL sources are sniffed with a ranged GET (`Range: bytes=0-63`) for typed `fetch-error` semantics, then handed to a native `<video>`/`<audio src>` so the browser streams and seeks via Range requests. Applies only when `requestInit` is plain (a media element cannot attach custom headers/method/credentials) — otherwise fetch-to-blob as usual. In-memory sources (Blob/File/ArrayBuffer/Uint8Array) always play from a blob URL.                                                                                                                                                                                                                                                                                |
| **Fit**                     | Fit is authoritative: it always scales media to fill the stage (down _or up_ — tiny media upscales without an absolute cap), so fit never leaves dead space. User zoom bounds are relative to fit: ceiling `maxScale × fitFactor`, floor `min(minScale, fitFactor)` — a fit-upscaled image must never hit a dead zoom cap.                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Interaction modes**       | Select mode (default; arrow cursor, never drag-pans, wheel **scrolls** clamped) vs. hand mode (`grab` cursor, drag pans **clamped to bounds** — media that fits the stage cannot move, overflowing media stops at its edges — and the wheel zooms). Toolbar toggle (arrow/hand icons, `aria-pressed`) + `h`/`v` keys. Zoom via buttons/pinch/double-click is mode-independent (touch pointers are tracked for pinch in both modes; mouse pointers still short-circuit in select so native selection survives). Pan for oversized 100% video works in hand mode. Text views skip mode machinery entirely — native scroll + native selection.                                                                                         |
| **Touch gestures**          | Coarse-primary-pointer devices (`matchMedia("(pointer: coarse)")`) trade redundant buttons for gestures (ADR-8): pinch replaces `Zoom in`/`Zoom out` (discrete `Fit`/`Actual size`/`Rotate` stay; video keeps `Fit`/`100%` since its pinch is off), and page views that opt in (`swipeNav`, PDF/PPTX only — XLSX keeps native horizontal scroll) get horizontal single-finger swipe paging in select mode, hiding the pager arrows while the `n / total` indicator stays. A second finger abandons a pending swipe for pinch; `pointercancel` navigates nothing. Hand mode keeps drag-to-pan (swipe is select-only).                                                                                                                |
| **Media controls**          | Toolbar-integrated playback controls owned by the Core (ADR-5): play/pause, seek + time, mute/volume; two-level video zoom (fit / 100%); kind-aware keyboard (space/arrows/m). Media elements mount with `controls = false` — no native control skin, hence no browser UI inside transform-scaled elements. Audio shows a placeholder card; the toolbar is the player.                                                                                                                                                                                                                                                                                                                                                              |
| **Text view**               | Native-scroll rendering of decoded text, sub-kind-aware: `plain` (raw), `code` (highlighted), `markdown` (**rendered HTML** on a paper card — `--flv-paper` surface, the PDF/DOCX page metaphor; ADR-6), `json` (pretty-print when parseable, else code), `csv` (RFC-4180 table, sticky header), `xml` (highlighted). No PanZoom; toolbar mode/transform groups hidden; native text selection. Source is truncated to the caps and shown with a notice otherwise.                                                                                                                                                                                                                                                                   |
| **Truncation**              | Text previews larger than the caps (2 MB bytes / 10 000 lines) render only the kept prefix with an in-view notice + download hint. Fires the `truncated` event (`{ bytes, lines }`, kept amounts) — an event, never a typed error. XLSX applies the same pattern per sheet with a 50 000-cell cap, adding an optional `cells` field to the detail (ADR-7).                                                                                                                                                                                                                                                                                                                                                                          |     |
| **Source toggle**           | Markdown-only toolbar button (`aria-pressed`) flipping the stage between rendered prose and the raw source highlighted as code. View-local state; resets to rendered on every new source.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Asset resolution**        | Per-reference URL policy for Markdown assets/links (ADR-6): `transformAssetUrl`/`transformLinkUrl` hook (raw reference → final URL, `null` → placeholder/stripped) → absolute URL as-is → relative against the `baseUrl` option, else the source URL (URL sources) → else placeholder. Plain `<img>` (CORS-exempt, lazy, `no-referrer`); **`requestInit` never applies to assets/links**. Non-fragment links open new tab + `noopener noreferrer`; `#fragment` scrolls in view. Failed/absent assets degrade to a styled placeholder, not a typed error.                                                                                                                                                                            |
| **Sub-kind**                | Text-family refinement carried by `ready` as `textKind`: `plain`, `code`, `markdown`, `json`, `csv`, `xml`. Refined during detection via MIME → extension → UTF-8/NUL sniff, before magic bytes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Office kinds**            | `docx`, `xlsx`, `pptx` are three first-class `FlvKind` values (ADR-7) — no umbrella kind. Fixed-size kinds (docx/pptx) use PanZoom fit/100%; xlsx is a native-scroll table (sticky header over zoom). Sheet/slide switching rides the pager slots (`pages`, `pagechange`). Detection may yield `encrypted-office` (CFB) before any engine loads; legacy `.doc`/`.xls`/`.ppt` → `unsupported-type`. Engines load per-kind as lazy chunks; office sources always fetch-to-blob.                                                                                                                                                                                                                                                       |     |
| **Lazy chunk**              | Separately-emitted bundles downloaded via dynamic import on first use: the **pdf.js bundle** (engine, inlined worker source, inlined asset archive — CMaps/standard fonts/wasm served in-memory) on first PDF preview, and the **text pipeline** (marked + DOMPurify + highlight.js) on first text view. Image previews never download either.                                                                                                                                                                                                                                                                                                                                                                                      |
| **Fake worker**             | pdf.js main-thread fallback used when a real Worker can't be created (CSP, cross-origin). Logs a warning, still renders.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Typed error**             | `{ code, message, cause? }` surfaced through the event bus — never an exception across the API boundary. Codes: `fetch-error`, `unsupported-type`, `encrypted-pdf`, `encrypted-office`, `render-error`, `aborted`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |     |
| **Event bus**               | One event stream, two views: `controller.on(name, cb)` with short names (`ready`, `error`, `close`, `pagechange`, `zoom`, `truncated`), and the same events as CustomEvents named `flv:<name>` bubbled on the Core's root element.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **`flv-` namespace**        | Reserved prefix for all CSS classes (`flv-toolbar`), DOM events (`flv:error`), and CSS custom properties (`--flv-accent`). Integrators must not define `flv-`/`flv:` names.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Playground**              | `playground/` — vanilla demo app run with `vp dev`; doubles as manual QA rig and documentation examples.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## Scope ledger (v1)

**In:** toolbar (select/hand mode toggle — pannable kinds; zoom in/out, fit, 100%, rotate — images/PDF only; page prev/next + indicator — PDF only; media controls — video/audio only, see ADR-5; download; fullscreen; close — Overlay only), interaction modes with clamped panning (hand default, select never pans), wheel/pinch zoom (mode-independent, bounds relative to fit), zoom persistence across PDF pages (pan re-centers), double-click toggle fit ↔ 2× fit (images/PDF; fullscreen toggle for video), keyboard (`Esc`, `+`/`-`, arrows, `0`, `h`/`v` — media kinds use space/arrows/m per ADR-5), progress/spinner loading state, error state with Retry, blob-URL lifecycle managed by the Core, native video/audio decode with typed `render-error` on codec failure, text family (plain/code/JSON/CSV/XML + rendered Markdown, ADR-6) with truncation guard, markdown source toggle, and the office family (docx/xlsx/pptx via per-kind lazy engines, ADR-7: docx-preview pages, SheetJS table with sticky header + cell cap, @aiden0z/pptx-renderer slides; `encrypted-office` detection; xlsx native scroll), and coarse-pointer touch gestures (ADR-8: mode-independent pinch with zoom buttons hidden, swipe paging with pager arrows hidden).

**Deferred (tracked, not built):** continuous PDF scroll (page-at-a-time for v1), search, thumbnails, outline, print, open-in-new-tab, multi-image gallery, password-protected PDF input (encrypted PDFs are detected and typed-errored), `data:`/`blob:`/`Response` sources, custom `fetch` injection, fetch-through asset loading (opt-in honoring `requestInit` for markdown assets), click-to-load gate for remote markdown images, image click-through from prose to the image view, swipe transition animation / rubber-banding, XLSX sheet swipe, desktop trackpad swipe, tap-to-toggle chrome.

## Tooling & packaging contract

- `flviewer`, unscoped, MIT. ESM-only npm package.
- Tooling: vite-plus end-to-end (`vp dev`, `vp test`, `vp check`, `vp pack --dts --publint --attw` as the release gate); dependencies via **pnpm** (`pnpm install`, `pnpm@12.4.1` pinned in `packageManager`). No npm/yarn lockfiles.
- Minimum browser target: evergreen (required by dynamic `import()`).
- Verification: Vitest + happy-dom unit tests (logic) + Vitest browser mode / Playwright Chromium smoke tests (real rendering, fixtures for PNG/JPEG/PDF).
